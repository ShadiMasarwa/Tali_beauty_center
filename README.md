# TALIÉ — מערכת לניהול תורים למכון יופי

פרויקט גמר מלא בעברית ובכיוון ימין־לשמאל. המערכת מאפשרת ללקוחות לקבוע תורים ללא הרשמה ולצוות המכון לנהל את היומן, הטיפולים, העובדות, שעות הפעילות והחסימות.

## טכנולוגיות

- צד לקוח: React, Vite ו־Bootstrap RTL
- צד שרת: Node.js ו־Express
- מסד נתונים: MongoDB מקומי באמצעות Mongoose
- הצפנת סיסמאות: Bcrypt
- עדכון תורים בזמן אמת: Socket.IO
- שפה: JavaScript בלבד, ללא TypeScript

## דרישות מוקדמות

יש להתקין במחשב:

1. Node.js בגרסה 20 ומעלה.
2. MongoDB Community Server.
3. VS Code או עורך קוד אחר.

## התקנה ראשונית

פתחו Terminal בתיקיית הפרויקט והריצו:

```bash
npm install
npm run install:all
```

לאחר מכן העתיקו את הקובץ `server/.env.example` לקובץ חדש בשם `server/.env` ואת `client/.env.example` לקובץ `client/.env`.

הגדרות ברירת המחדל מתאימות ל־MongoDB מקומי:

```env
PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/talie_beauty
CLIENT_URL=http://localhost:5173
SESSION_SECRET=replace_with_a_long_random_secret
INITIAL_ADMIN_PASSWORD=choose_a_private_password
NODE_ENV=development
```

יש להחליף את `SESSION_SECRET` במשפט אקראי וארוך.

## יצירת נתוני האתחול

ודאו ששירות MongoDB פועל והריצו:

```bash
npm run seed
```

הפעולה יוצרת שמונה טיפולים, שעות פעילות ומשתמשת מנהלת ראשונית:

- שם משתמש: `tali`
- סיסמה: הערך הפרטי שהוגדר ב־`INITIAL_ADMIN_PASSWORD`

מומלץ לשנות את הסיסמה לאחר הכניסה הראשונה.

## הפעלת הפרויקט

```bash
npm run dev
```

- אתר הלקוחה: `http://localhost:5173`
- מסך הניהול: `http://localhost:5173/admin`
- השרת: `http://localhost:5000`

## כללי קביעת תורים

- אין צורך ברישום לקוחה.
- ניתן לבחור טיפול אחד או יותר.
- לכל טיפול מתווספות חמש דקות מרווח.
- המערכת בודקת שעות פעילות, חסימות ותורים קיימים.
- רק תור אחד יכול להתקיים בכל זמן, גם כאשר יש כמה עובדות.
- שעות שכבר חלפו אינן מוצעות ביום הנוכחי.
- מספרי הטלפון נשמרים במסד הנתונים ללא מקפים.

## הרשאות

- מנהלת ועובדת יכולות לצפות ביומן ולנהל תורים.
- רק מנהלת יכולה לנהל עובדות, שעות פעילות וחסימות.
- כל משתמשת יכולה לשנות את הסיסמה שלה; מנהלת יכולה לאפס סיסמת עובדת.
- הסיסמאות נשמרות כגיבוב Bcrypt ואינן ניתנות להצגה מחדש.

## גיבוי וייצוא

במסך הניהול אפשר לייצא תורים ולקוחות לקובצי CSV. הקבצים נוצרים מהמידע האמיתי במסד הנתונים ומספרי הטלפון מוצגים בהם בתבנית קריאה.
